## Learning workflow

For each new concept, my goal is to follow an 8-step engineering discipline:

1. **Quest Briefing** — Understand why the concept matters in real AI systems.
2. **Simple Explanation** — Build intuition with everyday examples first.
3. **Manual Calculation** — Work through the math with small numbers by hand.
4. **Guided Coding** — Understand the structure and key lines of code.
5. **Independent Challenge** — Implement, experiment, debug, and verify.
6. **Boss Battle** — Test conceptual and practical mastery.
7. **GitHub Quest** — Run verification checks, document, and commit cleanly.
8. **Progression** — Review and reinforce before moving forward.
